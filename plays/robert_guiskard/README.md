# README: Robert Guiskard

Die Stufen und Charaktere für die Aufführung von Heinrich von Kleists Dramenfragment _Robert Guiskard, Herzog der Normänner_ (1808) vor den Mauern von Konstantinopel.

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um die erbitterte politische Staging-Strategie inmitten einer tödlichen biologischen Krise dreht. Während die Pest das normannische Lager zerfrisst, kämpft der Herzog gegen den inneren Verfall, um die dynastische Macht vor seinem feindseligen Neffen Abund zu retten.
