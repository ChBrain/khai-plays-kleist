# README: The Kant Crisis

Die Stufen und Charaktere für die Aufführung von Kleists philosophischem Wendepunkt - der Lektüre Immanuel Kants im Jahr 1801 - im Berliner Studierzimmer.

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um den Zusammenbruch von Kleists Erkenntnisglauben dreht. Das System modelliert den Kant-Schock als kognitive Katastrophe: Die Erkenntnis, dass wir die Welt nur durch grüne Brillengläser wahrnehmen können, zerstört Kleists bürgerlichen Lebensplan und treibt ihn zur Flucht aus den Wissenschaften und hin zur literarischen Radikalität.
