# README: Das Käthchen von Heilbronn

Die Stufen und Charaktere für die Aufführung von Heinrich von Kleists historischem Ritterschauspiel _Das Käthchen von Heilbronn_ (1810) auf den Burgen Schwabens und im Reich der prophetischen Träume.

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um das absolute, unbedingte Vertrauen einer jungen Frau dreht, das alle ständischen Konventionen und rationalen Einwände überschreitet. In der dualen Traumerfahrung zwischen Käthchen und Graf Wetter vom Strahl entfaltet sich eine metaphysische Wahrheit, die sich gegen die eitle, künstliche Täuschung der wachen Sinne behauptet - ein System, in dem das somnambule Bewusstsein den Weg zur wahren Bestimmung findet.
