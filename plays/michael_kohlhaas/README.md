# README: Michael Kohlhaas

Die Stufen und Charaktere für die Aufführung von Heinrich von Kleists Erzählung _Michael Kohlhaas_ (1810) an der sächsisch-brandenburgischen Grenze.

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um den tragischen Konflikt eines Rosshändlers dreht, dessen Gerechtigkeitssinn ihn - weil das Recht ihm verweigert wird - zum Rebellen und Brandstifter macht. Ein illegal geforderter Passzettel an der Grenze der Tronkenburg bildet den Ausgangspunkt einer Eskalation, die das Fundament des Staates erschüttert.
