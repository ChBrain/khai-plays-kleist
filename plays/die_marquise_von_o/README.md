# README: Die Marquise von O...

Die Stufen und Charaktere für die Aufführung von Heinrich von Kleists Novelle _Die Marquise von O..._ (1808) im Kastell von M... und auf dem Landgut V...

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um den unaufklärbaren Riss im Bewusstsein einer Frau dreht. Als Julietta nach einer Ohnmacht schwanger wird, gerät die moralische Weltordnung ihrer Familie ins Wanken. Die Zeitungsanzeige wird zum verzweifelten Werkzeug, das Unaussprechliche ins Licht der gesellschaftlichen Realität zu rufen.
