# README: Die Familie Schroffenstein

Die Stufen und Charaktere für die Aufführung von Heinrich von Kleists Trauerspiel _Die Familie Schroffenstein_ (1803) im schwäbischen Gebirge.

Dieses Dokument dient als Eintritt für die Stufe des Stücks, das sich um den tragischen Konflikt zwischen den Häusern Rossitz und Warwand dreht. Ein historischer Erbvertrag legt fest, dass der Besitz der einen Linie beim Aussterben an die andere fällt - ein Gesetz, das tiefen Argwohn und eine Kette blutiger Missverständnisse stiftet.
