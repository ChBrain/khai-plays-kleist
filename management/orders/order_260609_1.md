# Management Order: Guard main

## Direction

The house is raised and runs on lane PRs, but `main` is not yet protected:
direct pushes, force-pushes, and merges past failing gates are all still
possible. The gates (`test`, `khai-guard`, `branch-scope`, `consistency`) run on
every pull request, but they only advise until `main` requires them — the wall
the house leans on is, until then, painted on. khai-stage names branch
protection as a handoff the generator cannot perform: it lives in repository
settings, off-stage and beyond the Theatre Manager's tools, so it is a stop to
execute that escalates to the human. The Choregos direct that `main` be guarded
to match the Buechner house.

## Orders

1. The human (who alone holds merge and deploy authority) shall protect `main`:
   require a pull request before merging, require the gate checks to pass, and
   forbid force-pushes and deletion.
2. The required status checks shall be `test`, `khai-guard`, `branch-scope`, and
   `consistency` — the checks the house workflows already emit.
3. Administrator enforcement (`enforce_admins`) is the human's call: bind the
   maintainer to the gate, or keep an emergency bypass — but match whatever the
   Buechner house uses, so the estate is consistent.

## Implementation

Apply in **Settings → Branches → Add rule** for `main`, or in one call with the
GitHub CLI from a machine with admin rights (the agent's tools cannot set branch
protection):

    gh api -X PUT repos/ChBrain/khai-plays-kleist/branches/main/protection --input - <<'JSON'
    {
      "required_status_checks": { "strict": true,
        "checks": [ {"context":"test"}, {"context":"khai-guard"}, {"context":"branch-scope"}, {"context":"consistency"} ] },
      "enforce_admins": false,
      "required_pull_request_reviews": null,
      "restrictions": null,
      "allow_force_pushes": false,
      "allow_deletions": false
    }
    JSON

This order is a rider committed alone, so the guard homes it to the `governance`
lane.

## Targets

- [ ] Require a pull request before merging on `main`
- [ ] Require status checks `test`, `khai-guard`, `branch-scope`, `consistency` (strict / up to date)
- [ ] Forbid force-pushes and deletion of `main`
- [ ] Decide `enforce_admins` to match the Buechner house
- [ ] Confirm `main` reports as protected
